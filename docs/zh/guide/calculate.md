# {{ $frontmatter.title }}

四个方法覆盖了所有计算. `add` 与 `sub` 把日期移动一个给定偏移; `diff` 度量两个日期之间的间距; `len` 度量一个单位的大小.

## add(scope, offset)

把给定 scope 的字段加 offset:

```ts
import { od } from "@xtwis/ohday"

od("2023-10-01 12:30:45").add("d", 5).s // "2023-10-06 12:30:45"
od("2023-10-01 12:30:45").add("M", 4).s // "2024-02-01 12:30:45"
od("2023-10-01 12:30:45").add("y", -1).s // "2022-10-01 12:30:45"
```

offset 可以是负数. 内部 `add(scope, offset)` 等价于 `c(scope, g(scope) + offset)`, 因此继承了 `c` 的 [溢出处理](./change.md#溢出).

## sub(scope, offset)

减 offset:

```ts
od("2023-10-01 12:30:45").sub("h", 15).s // "2023-09-30 21:30:45"
od("2023-10-01 12:30:45").sub("M", 3).s // "2023-07-01 12:30:45"
```

等价于 `add(scope, -offset)`.

## 周的偏移

加 / 减一周内部按 `d += offset * 7` 实现:

```ts
od("2023-10-01 12:30:45").add("w", 1).s // "2023-10-08 12:30:45"
od("2023-10-01 12:30:45").sub("w", 2).s // "2023-09-17 12:30:45"
```

## diff(target, unit?, float?)

返回当前日期与目标日期的差. 当目标在当前日期的过去时返回正值.

```ts
od("2023-09-28 08:00:00").diff("2023-10-01 12:30:45", "d") // -3 (整数天)
od("2023-09-28 08:00:00").diff("2023-10-01 12:30:45", "d", true) // -3.18... (浮点天)
od("2023-10-01 12:30:45").diff("2023-10-02", "d") // 0 (不到 1 天)
od("2023-10-01 12:30:45").diff("2023-10-01", "d", true) // 0.52... (浮点)
od("2023-10-01 12:30:45").diff("2023-10-08 12:30:45", "w") // -1 (整周差)
od("2023-10-01 12:30:45").diff("2023-10-05 12:30:45", "w", true) // -0.57... (浮点周)
```

不传 `unit` 时结果以毫秒为单位. 第三个参数 `float` 在整数 (向 0 截断) 与浮点之间切换.

### 单位

| Unit | 行为                 |
| ---- | -------------------- |
| `y`  | 完整年数, 带符号校正 |
| `M`  | 完整月数, 带符号校正 |
| `w`  | 周 (截断)            |
| `d`  | 天 (截断)            |
| `h`  | 小时 (截断)          |
| `m`  | 分钟 (截断)          |
| `s`  | 秒 (截断)            |
| `ms` | 毫秒 (无截断)        |

`w`, `d`, `h`, `m`, `s` 的整数形式是 `Math.trunc(diffMs / unit)`. `y` 与 `M` 会做一次额外校正, 避免把相邻的年 / 月算成完整的.

### 年与月的校正

不做校正的话, `diffMs / MS_A_YEAR` 在很多情况下会偏离直觉. ohday 检测毫秒差与年差符号不一致的情形并做 ±1 校正:

```ts
od("2023-12-31").diff("2024-01-01", "y") // 0 (差 1 天, 不到 1 个完整年)
od("2023-12-31").diff("2024-01-01", "y", true) // -0.0027... (浮点, 无校正)
```

校正仅作用于整数输出. 浮点直接返回 `diffMs / MS_A_YEAR`.

## len(scope, unit?, float?)

返回给定 scope 的字段长度, 以给定 unit 度量:

```ts
od("2023-10-01 12:30:45").len("d", "h") // 24 (一天的小时数)
od("2023-10-01 12:30:45").len("M", "d") // 31 (10 月有 31 天)
od("2023-10-01 12:30:45").len("y", "d") // 365 (2023 不是闰年)
od("2023-10-01 12:30:45").len("w", "d") // 7 (一周的天数)
od("2023-10-01 12:30:45").len("w", "h") // 168 (一周的小时数)
```

内部 `len(scope, unit)` 等价于 `cs(scope).add(scope, 1).diff(cs(scope), unit)`. 第三个 `float` 参数与 `diff` 行为一致.
