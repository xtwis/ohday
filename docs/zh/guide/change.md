# {{ $frontmatter.title }}

三个方法覆盖了 OhDay 的所有变更. 每个方法都接受一个 scope flag 与一个可选的 value, 返回一个新实例.

## c(scope, value)

把给定 scope 的字段设为给定 value:

```ts
import { od } from "@xtwis/ohday"

od("2023-10-01 12:30:45").c("y", 2025).s // "2025-10-01 12:30:45"
od("2023-10-01 12:30:45").c("M", 2).s // "2023-02-01 12:30:45"
od("2023-10-01 12:30:45").c("d", 32).s // "2023-11-01 12:30:45" (Date 自动进位)
od("2023-10-01 12:30:45").c("h", 0).s // "2023-10-01 00:30:45"
```

变更是按位的. `c("d", 32)` 想要 10 月 32 日; JavaScript 的 Date 算术会进位到 11 月 1 日.

## 溢出

当改变年或月导致日期越界时, ohday 会回退到目标月的最后一天:

```ts
od("2024-02-29").c("y", 2025).s // "2025-02-28 12:00:00"
od("2023-01-31").c("M", 2).s // "2023-02-28 00:00:00"
```

判定逻辑是 set 之后 `Date.getDate() !== source.date`. JavaScript 的 Date 算术在原日期不存在于新月时已经会把日期往后推; ohday 再回退一天, 保证结果始终落在目标月之内.

## cs(scope, value?)

把给定 scope 的字段设为给定 value, 再把更下面的字段归零. `cs("M")` 落在该月 1 日 00:00:00:

```ts
od("2023-10-01 12:30:45").cs("y").s // "2023-01-01 00:00:00"
od("2023-10-01 12:30:45").cs("M").s // "2023-10-01 00:00:00"
od("2023-10-01 12:30:45").cs("d").s // "2023-10-01 00:00:00"
```

可选的第二个参数把 scope 设为另一个值:

```ts
od("2023-10-01 12:30:45").cs("M", 5).s // "2023-05-01 00:00:00"
od("2023-10-04 12:30:45").cs("w", 5).s // "2023-10-06 00:00:00" (周五 0 点)
```

## ce(scope, value?)

`cs` 的对偶. 把 scope 设为最大值, 再把下面所有字段填到各自层级的最大值:

```ts
od("2023-10-01 12:30:45").ce("y").s // "2023-12-31 23:59:59"
od("2023-10-01 12:30:45").ce("M").s // "2023-10-31 23:59:59"
od("2023-10-01 12:30:45").ce("d").s // "2023-10-01 23:59:59"
```

`M` 的最大日期由 `daysOfMonth(year, month)` 给出, 闰年 2 月自动处理.

## 周的处理

`w` flag 不出现在 `y`, `M`, `d`, `h`, `m`, `s`, `ms` 的内部顺序里. 它在上述方法执行之前会被换算成 `d` 的偏移:

```ts
od("2023-10-04 12:30:45").c("w", 0).s // "2023-10-01 12:30:45" (周三到周日)
od("2023-10-01 12:30:45").c("w", 3).s // "2023-10-04 12:30:45" (周日到周三)
od("2023-10-04 12:30:45").cs("w").s // "2023-10-01 00:00:00" (本周周日 0 点)
od("2023-10-01 12:30:45").cs("w", 3).s // "2023-10-04 00:00:00" (周三 0 点)
od("2023-10-04 12:30:45").ce("w").s // "2023-10-07 23:59:59" (本周周六 23:59)
od("2023-10-04 12:30:45").ce("w", 3).s // "2023-10-04 23:59:59" (周三 23:59)
```

源日期已经处于目标星期时, `c` 是 no-op, `cs` 与 `ce` 仅清零或置满时间部分.

安装了 [ISO Week 插件](../plugin/iso-week.md) 后, 同样的调用会产生不同结果. 默认情况下周日作为周首; ISO 周从周一开始.
