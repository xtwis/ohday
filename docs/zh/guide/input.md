# {{ $frontmatter.title }}

`od(input, format?)` 工厂接受 7 种输入形态. 选最贴近已有数据的那种, 每一种都会生成一个 OhDay.

## 字符串

最常用的形式. 不显式指定格式时, ohday 通过分隔符自动判断布局:

```ts
import { od } from "@xtwis/ohday"

od("2023-10-01 12:30:45") // "2023-10-01 12:30:45"
od("2023-10-01") // "2023-10-01 00:00:00"
od("2023-10-01T12:30:45Z") // ISO 8601 格式, T 与 Z 直接接受
```

三种分隔符会触发解析器: `-` 与 `/` 用于日期, `:` 用于时间, `T` 或空白用于日期与时间之间. 时间段里的 `.` 视为毫秒分隔符.

如果输入只有时间, 日期部分会用今天的日期补齐:

```ts
od("12:30:45") // 今天的日期 + 12:30:45
```

如果输入只有日期, 时间部分默认为 00:00:00.

## 自定义格式

第二个参数传格式串来控制解析:

```ts
od("01-10-2023", "DD-MM-YYYY") // "2023-10-01 00:00:00"
od("23-10-01 12:30", "YY-MM-DD HH:mm") // "2023-10-01 12:30:00"
```

格式串使用与输出一致的 token 词汇, 见 [核心概念](./concepts.md#token). 2 位年 token `YY` 会补齐成 `20YY`, 所以 `"23"` 变成 `2023`.

## 数组

数组输入按位置: `[year, month, date, hour, minute, second, ms?]`. 缺位遵循 [默认规则](#默认规则).

```ts
od([2023, 10, 1, 12, 30, 45]) // "2023-10-01 12:30:45"
od([2023, 10, 1]) // "2023-10-01 00:00:00"
od([2023, 10]) // "2023-10-01 00:00:00" (date 默认 1)
```

## 对象

对象输入按字段名. 缺字段同样遵循默认规则.

```ts
od({ year: 2023, month: 10, date: 1, hour: 12, minute: 30, second: 45 })
od({ year: 2023, month: 10 }) // "2023-10-01 00:00:00"
od({ hour: 12 }) // 今天的日期 + 12:00:00
```

可用的 key 包括 `year`, `month`, `date`, `day`, `hour`, `minute`, `second`, `ms`. `day` 是周几 (0 到 6, 0 是周日), 会把 `date` 调整到同一周对应的日期.

## Date, Number, OhDay

剩下的三种形态是直接对应:

```ts
od(new Date("2023-10-01")) // 拷贝 Date 对象
od(1696134645000) // Unix 时间戳, 单位毫秒
const d = od("2023-10-01")
od(d) // 返回一个内部 Date 相同的 OhDay
```

`number` 总是被当作 Unix 时间戳, 单位毫秒. 传入已有的 `OhDay` 时, 构造器读取其内部字段并克隆.

## 默认规则

缺字段的填充规则:

| 字段                             | 缺失时默认值                                    |
| -------------------------------- | ----------------------------------------------- |
| `year`                           | 当前年                                          |
| `month`                          | 若 `year` 已设置则为 1, 否则取当前月            |
| `date`                           | 若 `year` 或 `month` 已设置则为 1, 否则取当前日 |
| `hour`, `minute`, `second`, `ms` | 0                                               |

这也是为什么 `{ hour: 12 }` 返回今天 12:00:00 (year, month, date 都默认当前), 而 `{ year: 2023 }` 返回 2023-01-01 00:00:00 (month 与 date 都默认 1).
